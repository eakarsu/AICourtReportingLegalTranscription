# Controlled transcript runbook

Use `scripts/bootstrap.sh`, configure `.env`, and apply `scripts/migrate.sh` before the non-destructive `start.sh`. The launcher does not kill listeners or mutate the database. Demo seeding requires an explicit confirmation and is disabled for production.

The certified workflow migration records sealed/privileged matter boundaries, authorized media digests, chain-of-custody events, immutable transcript versions and accuracy metrics, page/line corrections, reporter certification, and controlled delivery attempts. Generated `gap_*` endpoints are no longer mounted. Media storage, speech processing, e-signature, court/matter systems, and billing remain external adapters with explicit failure/dead-letter states.

Before production: test access denial and legal holds, storage encryption and key rotation, word/diarization/timestamp/redaction/export fidelity on authorized media, delivery receipt reconciliation, reporter credential verification, and jurisdiction-specific certification. Software checks do not replace a licensed reporter.
